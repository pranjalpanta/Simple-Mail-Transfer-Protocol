# Simple Mail Transfer Protocol (SMTP) Server Lab

## 📌 Overview

This project demonstrates a basic SMTP server lab created for networking practice. SMTP is a protocol used to send and relay email messages between email clients and mail servers.

## 🎯 Objectives

* Understand the fundamentals of SMTP.
* Learn how email messages are sent through a mail server.
* Understand client-server communication.
* Practice basic SMTP server configuration and email delivery.

## 🖥️ Lab Topology

**Email Client → SMTP Server → Recipient Mail Server**

This topology illustrates the basic process of sending an email through an SMTP server.

## 🛠️ Technologies Used

* SMTP (Simple Mail Transfer Protocol)
* Email Client
* SMTP Server
* TCP/IP Networking

## 🧪 Lab Tasks

1. Configure a basic SMTP server.
2. Establish connectivity between the email client and SMTP server.
3. Configure the required email settings.
4. Send a test email through the SMTP server.
5. Verify successful email delivery.
6. Troubleshoot basic connectivity and configuration issues.

## 📚 What I Learned

* Fundamentals of SMTP and email delivery.
* Client-server communication.
* The role of mail servers in sending email.
* Basic network troubleshooting.

## 🔐 Security Considerations

* Use SMTP authentication where required.
* Use TLS encryption, such as STARTTLS or implicit TLS, when supported and properly configured.
* Avoid exposing an open mail relay to unauthorized users.
* Use strong passwords and restrict access to authorized clients.
